# Ghost Runner


Run from the ghosts and gas(red block) and survive for 1 minute until the timer goes down to zero

Every time you lose a new ghost appears ( Max 5)

W = Jump

D  = Move right

No left key to prevent accidents

Q = Dash

You can double jump
